# Eclipse Armor 汉化包（简体中文）

为 [Eclipse Armor](https://www.curseforge.com/minecraft/mc-mods/eclipse-armor) 模组（Forge 1.20.1）制作的简体中文语言包。

## 📦 下载

请前往 [Releases](https://github.com/MrGuo-JinS/eclipse-armor-zh-cn/releases) 页面下载最新版本的 `eclipse-armor-zhcn-v1.0.zip`。

## 📖 安装方法

1. 确保已安装 Eclipse Armor 原模组（Forge 1.20.1）
2. 下载本汉化包（`.zip` 文件）
3. 放入 `.minecraft/resourcepacks` 文件夹
4. 启动游戏 → 选项 → 资源包 → 启用本包

> 无需解压，无需修改模组文件。

## 📌 翻译内容

- 装备名称（6B47、6B45、MICH 2000、FAST、GPNVG-18 等）
- 护甲板名称与描述（米色 / 白色 / 黑色）
- UI 菜单与护甲板界面
- 按键提示与物品描述
